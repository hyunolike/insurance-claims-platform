## 스마트 기법
| 항목    | 정의 |
| ----- | --- |
| **S** | 6~8주 내 “보험금 청구 자동화 백엔드 MVP”를 배포해 고객/상담사 개입을 줄인다. |
| **M** | 현재 평균 처리 10분 → 7분 이하, 고객 문의 재오픈율 5% → 2% 이하를 목표로 한다. |
| **A** | Kafka, Redis, RDB 기반이며 Platform 팀의 이벤트 버스/모니터링 역량을 활용한다. |
| **R** | 보험금 청구 경험 개선 및 운영 비용 절감이라는 조직 KPI와 직접 연결된다. |
| **T** | 주차별 마일스톤: 2주 설계, 3주 개발, 1주 통합테스트, 1주 베타/피드백. |

### 측정/운영 계획
- 데이터팀과 협력해 평균 처리 시간·재오픈율 대시보드를 구성한다.
- 베타 기간 동안 고객 문의 태그를 `claim-automation`으로 분리해 회귀 여부를 확인한다.
