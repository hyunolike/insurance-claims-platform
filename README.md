## 커밋 메시지 규칙

| 타입 | 설명 | 예시 |
| --- | --- | --- |
| feat | 새로운 기능 추가 | `feat: 회원가입 이메일 인증 추가` |
| fix | 버그 수정 | `fix: 로그인 실패 시 토스트 노출` |
| docs | 문서나 주석 변경 | `docs: API 응답 규격 정리` |
| refactor | 기능 변화 없는 코드 개선 | `refactor: 결제 모듈 책임 분리` |
| test | 테스트 관련 작업 | `test: 결제 성공 시나리오 추가` |
| chore | 빌드, 패키지, 기타 유지보수 | `chore: 린트 의존성 업데이트` |

> 커밋 메시지는 `타입: 내용` 형태로 작성하고, 내용은 명령형으로 간결하게 요약합니다.
